# Shopify Chatbot Sprint

A [make.fun](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138) entry: one short plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## About

`main.py` writes the plan to `/output/entry.txt` (276 characters, no network, no dependencies beyond the Python standard library). The plan sells $49 AI support chatbots to Shopify stores with no live chat: day 1 builds one template plus a 30-second demo, days 2–30 are outreach to 100 stores a day, closing 2 clients a week at $49 setup + $19/month. Eight clients by day 30 means $392 in setup fees plus $152/month recurring.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
